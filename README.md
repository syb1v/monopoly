# Monopoly MVP 🎲

Мультиплеерный движок для настольной игры Монополия с реалтайм-синхронизацией.

## Основные возможности
*   **Полный цикл хода:** Броски кубиков, правило дублей, передвижение фишек.
*   **Экономика:** Покупка недвижимости, аренда, налоги.
*   **Развитие:** Постройка домов и отелей для увеличения аренды.
*   **Управление активами:** Возможность заложить и выкупить собственность.
*   **Тюрьма:** Классическая механика с попытками выбросить дубль или оплатой штрафа.
*   **Случайные события:** Карточки "Шанс" и "Общественная казна" с серверной валидацией.
*   **Аукционы:** Автоматический запуск аукциона при отказе от покупки.
*   **Сохранение:** Полноценная БД (SQLite) для сохранения состояния комнат.
*   **Интерфейс:** Всплывающие уведомления об изменении баланса, ошибках строительства, и встроенная книга правил.
*   **Адаптивность:** Поддержка мобильных устройств и планшетов.

## Стек технологий
*   **Бэкенд:** Python, FastAPI, WebSockets, SQLAlchemy
*   **Фронтенд:** React, Vite, Framer Motion

## Быстрый запуск

1.  **Запуск через общий скрипт (рекомендуется):**
    ```bash
    python run.py
    ```
    Скрипт автоматически поднимет бэкенд на порту 8000 и фронтенд на порту 5173/5174.

2.  **Ручной запуск бэкенда:**
    ```bash
    cd backend
    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    uvicorn main:app --reload
    ```

3.  **Ручной запуск фронтенда:**
    ```bash
    cd frontend
    npm install
    npm run dev
    ```
